# Benchmarks (ENG-09)

Gold-standard datasets and reproducible evaluation harness for STUDY-BUDDY's
parsing and extraction engines.

## Datasets

| Dataset | Location | Size | Description |
|---------|----------|------|-------------|
| Resume gold | `benchmarks/resume_gold/` | 30 synthetic (target: 120) | Name, email, phone, skills labeled |
| JD gold | `benchmarks/jd_gold/` | TBD (target: 60) | Must-have skills labeled |

Synthetic resumes cover: Indian formats (+91 phones), fresher/experienced,
multiple roles. Generated by `benchmarks/generate_gold.py` (seeded, reproducible).

## Running

```bash
# Quick (10 items)
python benchmarks/run.py --quick

# Full
python benchmarks/run.py
```

Results are written to `benchmarks/results.json`.
